Privacy policy

Margin of Loss publisher is a private, internal tool used only by Branislav Stojanovic, the owner of the YouTube channels Margin of Loss and Inside Seat, on those two channels. Last updated 8 November 2026.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What it accesses

Only after the channel owner signs in with Google and grants access, it uses the owner's own channels: it uploads and edits the channels' own videos, thumbnails, captions, playlists and the channel's own comments, and reads the channels' own YouTube Analytics reports. It does not access other people's accounts, and it does not collect data about viewers beyond the aggregated reports YouTube Analytics provides to the channel owner.

Where data is kept and how it is used

The sign-in token is stored only on the owner's own computer, in the Windows Credential Manager. Analytics reports are saved as files on that computer and used only by the owner to plan future videos. Nothing is sold, shared, shown to anyone else or sent to third parties. The tool uses no cookies and no tracking.

Deleting data and revoking access

Access can be revoked at any time at Google security settings (third-party access). When access is revoked the stored token stops working and the owner deletes it from the computer. Stored analytics files are deleted when they are no longer needed for planning, and within 30 days of a request to the contact below. Data obtained through the YouTube API Services is refreshed or deleted as those services' policies require.
